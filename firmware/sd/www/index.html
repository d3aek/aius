    Processing stages

    A checked stage runs; unchecking it bypasses that stage for latency and diagnostic comparisons. DTS framing and decoding cannot be bypassed. machine config

    Input channels

    Per-channel trim runs before the downmix. Each channel takes up to two EQ sections; none removes the section from the config, bypass keeps a present but inactive one.

    Output EQ

    Stereo post-mix sections, run on both channels.

    Downmix matrix

    Centre and surround gains are shared by both stereo sides by design, and are linear multipliers rather than decibels. With the clip-free policy selected the device resolves headroom itself.

    Limiter

    True-peak safety limiter on the output tail.
