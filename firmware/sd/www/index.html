    Feature bypass

    machine config

    Unchecking a stage bypasses it for latency and diagnostic comparisons. DTS framing and decoding cannot be bypassed.

    Input channels

    Per-channel trim runs before the downmix. Each channel takes up to two EQ sections; none removes the section from the config, bypass keeps a present but inactive one.

    Output EQ

    Stereo post-mix sections, run on both channels.

    Downmix matrix

    Centre and surround gains are shared by both stereo sides by design. With the clip-free policy selected the device resolves headroom itself.

    Limiter

    True-peak safety limiter on the output tail.
